Recover an Interrupted Organization Job

Follow a safe recovery workflow after a pause, cancellation, crash or disconnect. Inspect files before retrying.

Important: organization does not replace an independent backup.

1. Protect the source and note the interruption

Do not delete source files or restart blindly. Note whether the app was paused, cancelled, closed unexpectedly, or the destination disk disappeared.

2. Inspect the original and destination

Confirm the source is readable and the destination is writable. Check available space and open a few files from each location.

3. Read the activity log and copy report

Record completed operations and any errors or skipped files. A partial result is not proof that all files were processed.

4. Use Resume only when the app offers it

If the current operation can be resumed safely, use the app’s Resume control. Otherwise start a new COPY test into a clearly separated destination; do not blindly merge partial folders.

5. Verify and preserve evidence

Check samples, totals and errors, then retain backups and reports until the organized library has been verified.
