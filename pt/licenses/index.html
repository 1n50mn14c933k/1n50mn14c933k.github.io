Licenças de terceiros

1. Componentes de terceiros

O MEDIA KOLFAT pode incluir software open source, bibliotecas, codecs, frameworks e outros componentes sujeitos aos respetivos direitos de autor e licenças.

2. Licenças open source

As atribuições, textos de licença, referências ao código-fonte ou outros avisos exigidos serão disponibilizados de acordo com as licenças aplicáveis.

3. Lista específica da versão

O MEDIA KOLFAT 2.0.0 já foi lançado para Windows. As obrigações de licenciamento dependem dos componentes incluídos em cada versão. Os textos das licenças distribuídas continuam aplicáveis. Esta página não é uma lista completa e verificada.

Marcas e nomes de produtos de terceiros pertencem aos respetivos proprietários. Questões: Contactar KOLFAT.
