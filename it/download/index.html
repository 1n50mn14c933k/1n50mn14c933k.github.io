MEDIA KOLFAT • v2.0.0

Novità di MEDIA KOLFAT 2.0

La versione 2.0.0 migliora la selezione dei file, le cartelle di destinazione, le operazioni di rete e le opzioni d'installazione.

Scegli i tipi di file

Visualizza estensioni e conteggi prima di organizzare. Foto e video sono selezionati per impostazione predefinita; gli altri file sono facoltativi.

Sette cartelle intelligenti

Vengono create solo le cartelle necessarie, con destinazioni separate per duplicati e date sconosciute.

COPIA e SPOSTA

La modalità Guidata usa COPIA per impostazione predefinita. La modalità Avanzata offre COPIA o SPOSTA, con verifiche prima di eliminare i file di origine.

Migliorie per NAS

Lo spostamento tra archivi SMB/NAS è stato corretto e testato con oltre 20.000 foto.

I sette nomi delle cartelle

MEDIA KOLFAT crea solo le cartelle richieste. I nomi corrispondono a quelli dell'applicazione.
