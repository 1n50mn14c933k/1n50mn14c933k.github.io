Riprendere in sicurezza un'organizzazione interrotta

Cosa fare dopo pausa, annullamento, arresto improvviso o disconnessione di un disco senza rischiare gli originali.

Importante: organizzare i file non sostituisce un backup indipendente.

1. Proteggi gli originali e annota la causa

Non cancellare il materiale di origine e non riavviare alla cieca. Annota se l'operazione è stata sospesa, annullata o interrotta.

2. Controlla origine e destinazione

Verifica che i file siano leggibili, il disco di destinazione scrivibile e lo spazio sufficiente. Apri alcuni file di prova.

3. Consulta la cronologia e il rapporto COPY

Individua operazioni completate, errori e file saltati. Un risultato parziale non equivale al completamento di tutto.

4. Riprendi solo quando l'app lo consente

Usa Resume se la funzione è disponibile e sicura. In caso contrario, prova una nuova COPY in una cartella separata senza mescolare i file parziali.

5. Verifica prima di ripulire

Controlla campioni, quantità ed errori; conserva backup e rapporti fino alla completa verifica.
