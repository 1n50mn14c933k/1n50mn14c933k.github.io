Date EXIF mancanti? Organizza senza indovinare

Gestisci foto senza data affidabile, screenshot e immagini modificate.

Conserva un backup indipendente degli originali: organizzare non equivale a fare un backup.

1. Distingui le date

La data EXIF dello scatto è diversa da creazione e modifica del file.

2. Individua i casi dubbi

Screenshot, download e vecchie scansioni spesso non hanno una data di scatto affidabile.

3. Non inventare date

Non assegnare automaticamente la data attuale come data storica di acquisizione.

4. Controlla le fonti

Verifica cartelle originali, fusi orari e orologio della fotocamera; conserva il file originale.

5. Controlla il risultato

Esamina file senza data e report prima di correggere manualmente i metadati.
