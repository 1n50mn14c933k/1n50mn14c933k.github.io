MEDIA KOLFAT • v2.0.0

What's new in MEDIA KOLFAT 2.0

Version 2.0.0 improves file selection, destination organization, network handling and installer choice. These are verified release features, not upcoming promises.

Choose file types

See file extensions and their counts before organizing. Photos and videos are selected by default; Other Files is optional.

Seven smart folders

Only the folders needed for the selected files are created, including separate duplicates and unknown-date destinations.

COPY and MOVE

Guided Mode defaults to COPY. Advanced Mode supports COPY or MOVE, with verification safeguards before removing source files.

Better NAS handling

SMB/NAS-to-NAS MOVE handling was corrected and tested with a library containing more than 20,000 photos.

Four app languages

English, Persian with right-to-left layout, German and Spanish are available in the Windows application.

Safer file operations

Improved symbolic-link handling, operation safety, user interface and brand presentation.

The seven destination folder names

MEDIA KOLFAT creates only the folders needed for the files you select. These names match the application.
