COPY 还是 MOVE？安全整理照片

理解引导式复制、谨慎移动以及完成后的验证步骤。

安全第一：请独立备份重要原始文件。整理不能代替备份。

1. 保护原始文件

先在其他磁盘或备份系统中保存重要照片的独立副本。

2. 优先使用 Guided COPY

引导模式会创建整理后的副本，同时保留原始文件。

3. 谨慎选择 MOVE

Windows 高级模式允许明确选择 MOVE；Linux 测试版禁用了 MOVE，macOS 尚未公开发布。

4. 先测试少量文件

包括照片、视频、重复文件及日期不明的文件，并检查空间和写入权限。

5. 清理前验证结果

打开目标文件，检查数量和报告。不要仅因进度条完成就删除原始文件。
