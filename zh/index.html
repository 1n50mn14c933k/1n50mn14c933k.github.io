随着时间不断成长的实用软件

一个想法成为了 Media Kolfat。更多项目还会到来。

Kolfat 是一个不断成长的实用软件作品集，坚持一个原则：软件应解决真实问题、保持易懂，并让日常数字工作更轻松。

一切从 Media Kolfat 开始。

Media Kolfat 是 Kolfat 家族的第一个项目，用于帮助人们把散乱的照片和视频重新整理好。但 Kolfat 不会只停留在一个应用程序。

随着时间推移，只要有值得解决的问题，就会有新的软件加入。它们可能是传统桌面应用，也可能是轻量在线工具、Web 服务，甚至完全运行在浏览器中的软件。形式可以改变，目标不变：有明确目的、真正有用的软件。

持续成长的作品集

不同产品，同一标准。

Kolfat 的目标是成为一个专注型软件作品集，而不是单一应用。

实用优先每个项目都应该解决一个清晰、实际的问题。
保持易懂界面和工作流程应清晰，避免不必要的复杂性。
面向长期软件应保持可维护、可靠，并在首次发布之后仍值得使用。

桌面、Web 或纯在线。

Kolfat 不绑定单一平台。未来项目可以是 Windows 应用、浏览器工具、托管服务或其他软件形式。

今天的 Media Kolfat作品集从 Windows 媒体整理开始。
明天的新工具当新软件准备好并真正有用时，就会加入。
一个统一入口kolfat.app 将一直是发现整个作品集的中心。
