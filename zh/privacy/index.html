隐私政策

1. 概述

Kolfat 力求让个人信息处理保持清晰且最小化。MEDIA KOLFAT 主要用于整理您自己的照片和视频。

2. 您的媒体与本地处理

MEDIA KOLFAT 可能访问您选择的文件夹、照片、视频和元数据。核心功能设计为在您的设备上本地处理，您的媒体内容不会被出售。

3. 网站、Cookie 与技术数据

访问 kolfat.app 时，托管、DNS 或安全服务可能处理 IP 地址、浏览器、设备、请求页面和请求时间等必要技术信息。

4. 联系、共享、保留与安全

您通过电子邮件提供的信息用于回复您的请求。仅在必要时由服务提供商处理，不会出售，并仅保留必要期限。我们会采取合理的安全措施。

5. 您的权利与变更

根据您的居住地，您可能享有访问、更正、删除或限制处理等权利。联系：联系 KOLFAT。若产品、法律或处理方式发生重大变化，本政策将更新。

6. 可选的网站分析

仅在您明确同意后，kolfat.app 才会使用 Google Analytics 4（Google Ireland Limited）统计页面浏览量、大致地区、浏览器及设备信息，以及前往 Microsoft Store 或 GitHub 发行版的点击。未经同意，不会加载 Analytics 脚本或向 Google 发送分析数据。同意后可能设置分析 Cookie；个性化广告始终关闭。您可以通过“隐私设置”随时撤回同意。Google 可能在欧洲经济区以外处理数据；详情请查看 Google 隐私政策。 Google Privacy.
