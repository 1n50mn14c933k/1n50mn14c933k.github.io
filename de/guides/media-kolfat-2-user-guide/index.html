MEDIA KOLFAT 2.0

Benutzerhandbuch für MEDIA KOLFAT 2.0

Diese Anleitung führt vom ersten Start bis zu einer überprüften, geordneten Sammlung. Die Beispiele verwenden erzeugte Bilder und Videos mit unabhängigen Sicherungen. Alle Anwendungsbilder sind echte, nativ aufgenommene PNG-Dateien der installierten Windows-Anwendung.

Geprüft mit MEDIA KOLFAT 2.0.0, Build 2.0.0.0. Die Bildschirmbilder zeigen die englische Oberfläche. Beim größeren Beispieldatensatz ändern sich die Zahlen; beachten Sie beim Nachvollziehen Ihre eigenen Werte.

Erstellen Sie vor der Organisation eine unabhängige Sicherung. COPY wird empfohlen, weil die Quelldateien erhalten bleiben. Advanced MOVE entfernt Quelldateien nach Prüfung des Ziels und weiteren Sicherheitsprüfungen. Bewahren Sie die Sicherung auf, bis Ziel und Bericht überprüft sind.

1. Starten und die Benutzerführung verstehen

Starten Sie die installierte Anwendung. Die Seitenleiste enthält Performance Check, Add Photos & Videos, Photos Health Check, Duplicate Finder, Browse Library, Organize Photos & Videos, Activity, Settings und About. Unter Experience wählen Sie Guided oder Advanced.

  1. Schritt 1. Wählen Sie zunächst Guided unter Experience. Folgen Sie der hervorgehobenen Empfehlung. Kommende Schritte sind neutral grau, der aktuelle Schritt ist gelb beziehungsweise bernsteinfarben betont, abgeschlossene Schritte erhalten grüne Häkchen.

  2. Schritt 2. Starten Sie Quick Check auf Performance Check und warten Sie auf das Ende. Lesen Sie das Ergebnis: Der Beispielcomputer erreichte 98 Prozent; auf anderen Computern kann der Wert abweichen.

  3. Schritt 3. Öffnen Sie Add Photos & Videos. Zur Auswahl stehen Scan Computer Automatically und Choose Photos & Videos Manually. Wählen Sie die manuelle Auswahl, wenn Ihnen der gewünschte Medienordner bekannt ist.

  4. Schritt 4. Öffnen Sie About. Klappen Sie gegebenenfalls Release Information auf und lesen Sie Version und Build. Über die Seitenleiste kehren Sie zum gewünschten Ablauf zurück.

  5. Schritt 5. Öffnen Sie Privacy & Data Safety. Lesen Sie die Unterschiede zwischen Scannen, COPY und Advanced MOVE. Bewahren Sie eine unabhängige Sicherung wichtiger Medien auf.

  • Der animierte Pfeil und das Leuchten kennzeichnen die empfohlene nächste Aktion. In Settings stehen Reduced motion und weitere Führungseinstellungen bereit.
  • Guided hilft bei der Reihenfolge der Aufgaben. Advanced bietet einen direkteren Ablauf und zeigt MOVE, sobald ein Organisationsplan bereitsteht.
  • About enthält außerdem Legal & Policies, Support, Technical Information, Open-Source & Third-Party Licenses und Product Information. Öffnen Sie bei Bedarf den passenden Bereich.

Sie können die installierte Version feststellen, zwischen Seiten wechseln und den aktuellen geführten Schritt erkennen.

2. Eine Quelle manuell auswählen

Eine Quelle ist ein im lokalen Katalog registrierter Ordner. Hinzufügen und Scannen erfassen unterstützte Fotos und Videos. Das Beispiel enthält in Unterordnern 14 erzeugte JPEG-Dateien, zwei erzeugte AVI-Dateien und eine optionale Textdatei.

  1. Schritt 1. Wählen Sie Choose Photos & Videos Manually. Prüfen Sie im Ordnerdialog Current folder, Locations, Folders und Photos & Videos in this folder, bevor Sie etwas auswählen.

  2. Schritt 2. Tragen Sie den vollständigen Pfad des gewünschten Katalogordners in Current folder ein. Im Beispiel ist dies Media Samples im ausschließlich für Vorführungen verwendeten Verzeichnis.

  3. Schritt 3. Wählen Sie Go. Prüfen Sie Pfad und Unterordnernamen. Im übergeordneten Ordner können direkt keine Medien liegen, obwohl seine Unterordner unterstützte Dateien enthalten.

  4. Schritt 4. Öffnen Sie einen bekannten Unterordner und prüfen Sie die Vorschauen. Im Beispiel zeigt 2024 Holiday sechs erzeugte JPEG-Bilder.

  5. Schritt 5. Wählen Sie Up one folder, um die gesamte verschachtelte Sammlung einzubeziehen. Prüfen Sie Current folder erneut.

  6. Schritt 6. Wählen Sie Select This Folder. Prüfen Sie unter Ready to add this folder den Namen und vollständigen Pfad. Fahren Sie bei einer unerwarteten Quelle nicht fort.

  7. Schritt 7. Öffnen Sie bei Bedarf Advanced options. Prüfen Sie Folder location, den optionalen Anzeigenamen und Folder type. Cloudordner müssen bereits auf diesem Computer verfügbar sein; wählen Sie einen lesbaren lokalen Pfad.

  8. Schritt 8. Starten Sie den angebotenen Scan und warten Sie auf Ready sowie einen erfolgreichen Scanzeitpunkt. Die erste Beispielquelle enthält 16 unterstützte Medien; ihre Textdatei wird nicht als Medium katalogisiert.

  9. Schritt 9. Verwenden Sie Refresh auf dieser Quellenkarte für einen erneuten Scan. Prüfen Sie Status und Zeitpunkt. Refresh wählt die Quelle nicht automatisch für die Organisation aus.

  • Ein weiterer Ordner kann in Advanced zunächst hinzugefügt werden. Auf seiner Karte erscheint Start Scan. Im gezeigten geführten Ablauf wird der erste Ordner anfangs automatisch gescannt.
  • Prüfen Sie im Organizer immer erneut Selected Folder. In der geprüften Oberfläche ändert Refresh auf einer Quellenkarte die ausgewählte Organisationsquelle nicht.

Der richtige Ordner ist registriert; seine unterstützten Medien stehen im Katalog bereit.

3. Automatische Suche und Speicherorte

Der Quelldialog bietet This PC, lokale Ordner und Laufwerke, Pictures, OneDrive und Network. Wählen Sie nur gewünschte Leseorte. Externe oder USB-Laufwerke müssen angeschlossen und lesbar sein, Netzwerkorte bereits über Windows erreichbar.

  1. Schritt 1. Prüfen Sie Scan Computer Automatically vor der Auswahl. Die Funktion startet eine computerweite Suche und bietet keine Begrenzung auf den Beispielordner. Verwenden Sie die manuelle Auswahl, wenn Sie nur einen bekannten Ordner einlesen möchten.

  2. Schritt 2. Verwenden Sie This PC für ein lesbares Laufwerk oder geben Sie einen genauen lokalen beziehungsweise Netzwerkpfad unter Current folder ein. OneDrive bezieht sich auf lokal verfügbare Dateien. Stellen Sie nicht verfügbare Inhalte zuerst über Windows bereit.

  • Die computerweite automatische Suche wurde hier nicht ausgeführt, da sie Laufwerke außerhalb der Beispieldaten prüfen würde. Es wird kein automatisches Suchergebnis als getestet dargestellt.
  • Eine Ortsverknüpfung bedeutet keine Anmeldung oder bestätigte Cloudverbindung. Persönliche Pictures-, OneDrive-, Netzwerk- und externe Medienbestände wurden nicht geöffnet.

Sie können eine Auswahlmethode wählen, die zum Speicherort und zum beabsichtigten Scanumfang passt.

4. Vorschauen und Mediendaten prüfen

Öffnen Sie Photos Health Check nach einem Quellscan. Vorschauzustand, Datumsinformationen und Verfügbarkeit der Originale sind unterschiedliche Prüfungen. Eine fehlende Vorschau bedeutet nicht automatisch eine fehlende Quelldatei.

  1. Schritt 1. Prüfen Sie die Summen. Im kleinen Beispiel gibt es 16 Medien: 14 gültige Vorschauen und zwei Videovorschauprobleme. Alle 16 Originale wurden zuletzt als verfügbar erkannt.

  2. Schritt 2. Starten Sie die ausdrücklich angebotene Reparatur fehlender Vorschaubilder. Hier wurden zwei Videos geprüft, keine Vorschau repariert und beide Formate für die Vorschauerzeugung als nicht unterstützt gemeldet.

  3. Schritt 3. Starten Sie die angebotene erneute Analyse fehlender Datumsangaben. Prüfen Sie die Herkunft: Hier wurden alle 16 Daten mit Filesystem last modified bestimmt. Das kann Kopieren oder Bearbeiten statt der Aufnahme widerspiegeln.

  4. Schritt 4. Öffnen Sie Settings und Advanced date policy. Lesen Sie die aktivierten Quellen: eingebettete Metadaten, unterstützte XMP-Dateien, Dateinamen, strukturierte Ordner und letztes Änderungsdatum. Windows CreationTime gilt nicht als Aufnahmedatum.

  • Die erzeugten Dateien enthalten keine Kamera-Aufnahmemetadaten. Ihre Namen mit 2024 oder 2025 bestimmten das beobachtete Ergebnis nicht; verwendet wurde das letzte Änderungsdatum des Dateisystems.
  • Bei einem nicht unterstützten Vorschauformat kann eine Reparatur ohne verbesserte Vorschau enden. Bewahren Sie die Originale auf und verwenden Sie bei Bedarf einen geeigneten Betrachter.

Sie können Vorschau-, Datums- und Verfügbarkeitsprobleme unterscheiden und das tatsächliche Reparaturergebnis lesen.

5. Exakte Duplikate finden und prüfen

Duplicate Finder vergleicht unterstützte, verfügbare Katalogmedien auf exakte Kopien. Gleiche Namen allein beweisen kein Duplikat. Der kleine Beispieldatensatz enthält absichtlich drei Gruppen identischer Dateien.

  1. Schritt 1. Öffnen Sie Duplicate Finder nach dem Quellscan. Prüfen Sie die Anzahl der bereitstehenden Medien und wählen Sie Find Duplicates.

  2. Schritt 2. Warten Sie auf Duplicate scan complete. Im ursprünglichen Beispiel wurden drei Gruppen, sechs Duplikatdateien und etwa 16,9 MB potenziell freigebbarer Speicher gefunden.

  3. Schritt 3. Scrollen Sie durch Exact Duplicate Group. Vergleichen Sie Namen, Orte und Größen. Open Folder hilft beim Auffinden einer Datei; das Prüfen einer Gruppe entfernt nichts.

  4. Schritt 4. Beobachten Sie bei größeren Sammlungen Finding exact duplicates und die geprüften Kandidaten. Der größere Test enthält 544 Katalogmedien. Währenddessen zeigt der geprüfte Build Stop Scan.

  5. Schritt 5. Wählen Sie Stop Scan, um eine laufende Suche zu beenden. Im Beispiel erschien wieder die Startbereitschaft. Eine abgebrochene Suche ist unvollständig und beweist nicht, dass keine Duplikate vorhanden sind.

  • Duplicate Finder zeigte in diesem installierten Build keine Schaltflächen Pause oder Resume. COPY besitzt eigene, später gezeigte Pause- und Resume-Steuerungen.
  • Die geprüfte Duplikatoberfläche bietet keine Löschaktion. Potenziell freigebbarer Platz ist eine Schätzung, kein bereits freigegebener Speicher. Behalten Sie mindestens eine unabhängig geprüfte Kopie und ihre Sicherung.
  • Eine neue Suche oder Quellenänderung kann ein vorheriges Ergebnis ungültig machen. Achten Sie in der Übersicht auf Not checked, bevor Sie Duplikatzahlen verwenden.

Sie können exakte Duplikate suchen, Gruppen prüfen und die Suche beenden, ohne Originaldateien zu löschen.

6. Medien durchsuchen, auswählen und drehen

Browse Library verbindet eine Übersicht mit einer durchsuchbaren Galerie. Prüfen Sie Photos & Videos, Health, Duplicates, Unknown Date und Organization. Die folgenden Drehbeispiele verwenden die kleine Sammlung; jede Änderung wird mit Undo zurückgenommen.

  1. Schritt 1. Öffnen Sie Browse Library. Prüfen Sie Übersicht und Karten. Das erste Beispiel enthält 14 Fotos und zwei Videos; für nicht verfügbare Videovorschauen erscheinen Platzhalter.

  2. Schritt 2. Geben Sie garden in Search media ein. Im kleinen Datensatz erscheinen sieben passende Fotodateien. Verwenden Sie für eigene Suchen einen bekannten Teil des Dateinamens.

  3. Schritt 3. Markieren Sie das Kontrollkästchen einer Fotokarte. Prüfen Sie die Auswahl vor einer Aktion. Die Drehsteuerung gehört zum ausgewählten Foto.

  4. Schritt 4. Wählen Sie Rotate Right für das Foto und prüfen Sie seine Vorschau. Die Drehung wird für Katalogvorschau und organisierte beziehungsweise exportierte Kopien gespeichert; das Quellbild bleibt unverändert.

  5. Schritt 5. Wählen Sie Undo für dieses Foto. Prüfen Sie, ob die frühere Ausrichtung wiederhergestellt ist.

  6. Schritt 6. Wählen Sie Select all visible photos. Prüfen Sie die Auswahlzahl in der Werkzeugleiste: Hier sind es die sieben sichtbaren Fotoergebnisse.

  7. Schritt 7. Wählen Sie Rotate Left für die Gruppe. Prüfen Sie die ausgewählten Vorschauen, während die Auswahl bestehen bleibt.

  8. Schritt 8. Wählen Sie das gemeinsame Undo, bevor Sie eine weitere Drehung ausprobieren. Die vorherigen Ausrichtungen werden wiederhergestellt.

  9. Schritt 9. Wählen Sie Rotate 180 für die Gruppe. Prüfen Sie mehrere Vorschauen und nicht nur die Werkzeugleiste.

  10. Schritt 10. Wählen Sie erneut Undo. Im Beispiel wurden alle Drehungen vor der Organisation zurückgenommen; die Hashwerte der Originale blieben unverändert.

  11. Schritt 11. Wählen Sie Clear Selection nach der Gruppenaktion. Prüfen Sie, ob die Auswahlleiste zurückgesetzt ist.

  12. Schritt 12. Leeren Sie Search media, um zur größeren Galerie zurückzukehren. Gesetzte Filter können die Anzeige weiterhin einschränken.

  13. Schritt 13. Wählen Sie Photos only im Medientypfilter. Das spätere Beispiel zeigt 28 Fotoeinträge, weil eine zweite ausschließlich für Tests verwendete Quelle hinzugefügt wurde.

  14. Schritt 14. Wählen Sie File name A–Z und schließen Sie die Sortierliste. Weitere gezeigte Möglichkeiten sind neueste, älteste, umgekehrte Dateinamen, größte, kleinste, Fotos zuerst und Videos zuerst.

  • Die Bibliotheksanzahl beschreibt Katalogeinträge und kann Kopien aus separat registrierten Quellen einschließen. Ein höherer Wert bedeutet nicht, dass ein COPY-Ziel automatisch registriert wurde.
  • Nach den Drehbeispielen wurden Originale und unabhängige Sicherungen per Hash geprüft. Keine dieser Dateien wurde durch die Ausrichtungsänderungen bearbeitet.

Sie können Fotos finden, Auswahlen steuern, Ergebnisse sortieren und Vorschauausrichtungen sicher ändern oder zurücknehmen.

7. Eine geführte COPY-Organisation abschließen

Verwenden Sie COPY für den ersten Organisationsdurchlauf. Halten Sie eine geprüfte unabhängige Sicherung bereit und wählen Sie ein separates Ziel mit ausreichend Platz. Das abgeschlossene Beispiel kopiert die ursprünglichen 16 unterstützten Medien.

  1. Schritt 1. Öffnen Sie mit ausgewähltem Guided die Seite Organize Photos & Videos. Prüfen Sie im Dialog Choose File Types die gescannten, ausgewählten und ausgeschlossenen Mengen.

  2. Schritt 2. Wählen Sie Deselect All, um die Auswahl neu aufzubauen. Ohne ausgewählten Typ ist Continue nicht verfügbar. Wählen Sie mindestens einen unterstützten Typ.

  3. Schritt 3. Wählen Sie Select All. Im Beispiel werden dadurch 17 Dateien einschließlich der optionalen Textdatei ausgewählt.

  4. Schritt 4. Deaktivieren Sie .txt. Prüfen Sie vor dem Fortfahren: 17 gescannt, 16 ausgewählt, eine ausgeschlossen.

  5. Schritt 5. Wählen Sie Continue. Prüfen Sie Selected Folder und den vollständigen Pfad, bevor Sie das Organisationsmuster einstellen.

  6. Schritt 6. Wählen Sie Year / Month / Day in Pattern und schließen Sie die Liste. Prüfen Sie Plan und Kategorien vor der Zielauswahl. Dieser Plan verwendet die unveränderte ursprüngliche Quelle mit 16 Medien.

  7. Schritt 7. Wählen Sie Change Location für ein bestimmtes Ziel. Der native Windows-Dialog benötigt einen vorhandenen Ordner, getrennt von Quelle und Sicherung.

  8. Schritt 8. Geben Sie das gewünschte Ziel ein oder navigieren Sie dorthin und wählen Sie Select Folder. Im Beispiel ist dies Copy Results. MEDIA KOLFAT legt darunter MEDIA KOLFAT Organized Media an.

  9. Schritt 9. Lesen Sie Selected destination und prüfen Sie Kategorien sowie freien Platz. Nach der abgeschlossenen Duplikatsuche ordnet dieses Beispiel exakte Kopien den Kategorien für doppelte Fotos und Videos zu.

  10. Schritt 10. Wählen Sie Copy Selected Files. Lesen Sie Confirm copy: Originale bleiben unberührt, es entstehen nur neue Kopien. Wählen Sie Cancel bei falscher Quelle, Auswahl oder Zielangabe.

  11. Schritt 11. Bestätigen Sie Copy Selected Files und warten Sie. Das Beispiel endet mit 16 kopiert, null identischen übersprungen, null umbenannt und null fehlgeschlagen. Prüfen Sie Berichtspfad und Kategorien.

  • Zu den Mustern gehören Year / Month / Day, YMD - Single Folder, Year / Month, Kameravarianten, Year Only, Month Only, Day Only und Custom. Wählen Sie eine verständliche Struktur und prüfen Sie deren Vorschau.
  • Open destination und Open Folder öffnen Ergebnisordner. Save report speichert eine Berichtskopie. Add Destination to Folders registriert das Ziel ausdrücklich; dies geschieht nicht automatisch.
  • Alle 16 Zielhashwerte entsprachen den erwarteten Quelldateien. Alle 17 ursprünglichen Dateien und ihre unabhängigen Sicherungen blieben unverändert.

Im gewählten Ziel liegt eine geprüfte geordnete Kopie mit Textbericht vor; sämtliche Originale bleiben erhalten.

8. COPY pausieren, fortsetzen, stoppen und wiederholen

Bei längeren Vorgängen können Sie den Fortschritt lesen. Das größere Beispiel verwendet 512 erzeugte Videokopien mit einer unabhängigen geprüften Sicherung. Es handelt sich ausschließlich um entbehrliche Testdateien.

  1. Schritt 1. Wählen Sie für das größere Beispiel ein separates Ziel und prüfen Sie dessen vollständigen Pfad. Hier wird Copy Timing Results verwendet.

  2. Schritt 2. Prüfen und bestätigen Sie COPY nach Kontrolle von Quelle, Auswahl, Ziel und freiem Platz. Vor dem Kopieren kann eine kurze Vorbereitung erscheinen.

  3. Schritt 3. Wählen Sie Pause und warten Sie auf Resume. Der Vorgang pausiert sicher; möglicherweise wird zunächst die aktuelle Datei fertiggestellt.

  4. Schritt 4. Wählen Sie Resume für dieselbe aktive Operation. Während der weiteren Verarbeitung erscheint Pause wieder.

  5. Schritt 5. Wählen Sie Stop und lesen Sie Abbruchübersicht und Bericht. Beim ersten größeren Versuch blieben 110 fertige Kopien bei null Fehlern erhalten. Der Abbruch entfernte diese gültigen Kopien nicht.

  6. Schritt 6. Starten Sie COPY erneut mit identischer Quelle, identischem Muster und Ziel. Prüfen Sie die neue Bestätigung. Bereits abgeschlossene identische Dateien können bei dieser neuen Operation übersprungen werden.

  7. Schritt 7. Lesen Sie Dateinamen, Dateizahl und Prozentsatz im Fortschrittsbereich. Beim erneuten Versuch bezieht sich die Zahl auf noch zu kopierende Dateien statt auf schon abgeschlossene identische Dateien.

  8. Schritt 8. Pausieren Sie bei Bedarf erneut und warten Sie auf Paused. Zahl und Prozentsatz beschreiben die tatsächlich pausierte Operation.

  9. Schritt 9. Wählen Sie Resume und lassen Sie die Operation enden. Halten Sie das Ziel verbunden und verändern Sie die Quellen währenddessen nicht.

  10. Schritt 10. Prüfen Sie die Endübersicht: 402 verbleibende Dateien kopiert, 110 identische übersprungen, null umbenannt, null fehlgeschlagen. Anschließend wurden alle 512 Zielmedien per Hash überprüft.

  • Das Stoppen einer Duplikatsuche ist ein anderer Vorgang als das Stoppen von COPY. Verwenden Sie die Steuerung der tatsächlich laufenden Operation.
  • Die geprüfte COPY-Seite kann oberhalb der aktiven Steuerung früheren Statustext beibehalten. Für den aktuellen Vorgang sind Fortschrittsanzeige und Endergebnis maßgeblich.
  • Prüfen Sie nach einem Abbruch Bericht und Ziel. Bewahren Sie abgeschlossene geprüfte Dateien auf; das gesamte Ziel muss nicht pauschal gelöscht werden.

Sie können COPY pausieren, fortsetzen, sicher stoppen und erneut starten, ohne bereits abgeschlossene identische Dateien zu verdoppeln.

9. Advanced MOVE mit Sicherung verwenden

MOVE ändert den Speicherort der Quelldateien. Üben Sie nur mit entbehrlichen Kopien und behalten Sie eine unabhängig geprüfte Sicherung. Das Beispiel verwendet den separat gesicherten Klon Move Samples; die ursprüngliche Beispielquelle wird nie für MOVE benutzt.

  1. Schritt 1. Wählen Sie Advanced unter Experience. Der geführte Fortschrittsstreifen ist dann nicht die zentrale Navigation. Wählen Sie vor der Organisation die richtige Testquelle.

  2. Schritt 2. Bestätigen Sie die Dateitypen und prüfen Sie Selected Folder. Das Beispiel zeigt ausdrücklich Move Samples mit genauem Pfad sowie 17 gescannt, 16 ausgewählt und eine ausgeschlossen.

  3. Schritt 3. Bestätigen Sie Year / Month und prüfen Sie den Plan. Dieser MOVE verwendete keine abgeschlossene Duplikatklassifizierung; der Plan zeigt Duplicates: Not checked.

  4. Schritt 4. Wählen Sie Change Location und den separaten Ordner Move Results. Prüfen Sie den Pfad vor der Bestätigung.

  5. Schritt 5. Wählen Sie Move unter Transfer mode. Lesen Sie: Zieldateien werden vor Quellentfernung geprüft, Quellordner bleiben erhalten und ein detaillierter Bericht wird im Ziel gespeichert.

  6. Schritt 6. Wählen Sie Move Selected Files und lesen Sie Confirm move. Geprüfte Zieldateien bleiben erhalten, ihre genauen Quelldateien werden entfernt. Brechen Sie bei Unsicherheit mit Cancel ab.

  7. Schritt 7. Bestätigen Sie erst nach Prüfung von Quelle, Ziel und Sicherung. Warten Sie auf Move complete und lesen Sie die Zahlen: 16 verschoben, null kopiert mit Quelle erhalten, null fehlgeschlagen.

  8. Schritt 8. Öffnen Sie Activity und suchen Sie Move Photos & Videos mit Completed. Prüfen Sie Zahlen und Open Move Report. Die unabhängige Sicherung muss weiterhin verfügbar bleiben.

  • Die 16 Zielhashwerte stimmten mit den erwarteten Dateien überein. Alle 17 unabhängigen Sicherungsdateien blieben unverändert. Die ausgeschlossene notes.txt und alle vier Quellunterordner blieben erhalten.
  • COPIED_SOURCE_RETAINED bedeutet: Die Zielkopie existiert, aber die Quelle wurde behalten. Prüfen Sie diesen Berichtseintrag, statt von einer vollständig entfernten Quelle auszugehen.
  • Prüfen Sie Selected Folder vor jeder Operation. Refresh auf einer anderen Quellenkarte ändert die Organisationsquelle nicht. Hier wurde eine Testquelle ausschließlich aus dem Katalog entfernt und erneut hinzugefügt, um sie auszuwählen.

Der ausschließlich für Tests verwendete MOVE ist überprüft abgeschlossen; unabhängige Sicherung und ursprüngliche Sammlung sind unversehrt.

10. Activity und Textberichte lesen

Activity protokolliert lokale Vorgänge. Lesen Sie Status und Mengen gemeinsam: Completed, Completed with warnings und Cancelled bedeuten unterschiedliche Ergebnisse. Automatische COPY- und MOVE-TXT-Berichte liegen im gewählten Zielstammordner.

  1. Schritt 1. Öffnen Sie Activity nach einem Vorgang. Suchen Sie Copy Photos & Videos und vergleichen Sie verarbeitet, kopiert, übersprungen und fehlgeschlagen mit der Zielübersicht.

  2. Schritt 2. Vergleichen Sie abgeschlossene und abgebrochene Vorgänge. Der abgebrochene COPY verarbeitete 110 Dateien; die spätere Wiederholung 512 mit 110 übersprungenen. Eine abgebrochene Duplikatsuche liefert kein vollständiges Ergebnis.

  3. Schritt 3. Verwenden Sie Open Copy Report beziehungsweise Open Move Report beim richtigen Eintrag. Open Destination führt zum Ergebnisordner. Prüfen Sie Modus, Quell- und Zielangaben, Statuszeilen und Endsummen im TXT-Bericht.

  • Der geprüfte MOVE-Bericht enthält Mode: MOVE, Total planned files: 16, Moved: 16, COPIED_SOURCE_RETAINED: 0, Skipped: 0 und Failed: 0.
  • Der ursprüngliche COPY-Bericht bestätigt den Erhalt der Quelldateien. Der Abbruchbericht nennt die abgeschlossenen Dateien, die im Ziel verblieben sind.
  • Clear Activity History ist vorhanden, wurde aber nicht verwendet. Der Verlauf bleibt für die Nachprüfung erhalten.

Sie können Aktivität, Zielordner und Bericht zuordnen und Erfolg von unvollständiger Verarbeitung unterscheiden.

11. Einstellungen und Neustart des Katalogs verstehen

Settings gelten lokal. Prüfen Sie Language, Experience, Safety, Privacy & Local Processing, Organizing, Library, Guidance & Accessibility, Maintenance und Media dates. Lesen Sie vor einer Wartungsbestätigung deren Folgen.

  1. Schritt 1. Öffnen Sie Settings. Wählen Sie eine angebotene Sprache, prüfen Sie Guided und Advanced sowie Safety. Organisationsbestätigung und Warnung vor Quellenentfernung sind in der gezeigten Oberfläche verpflichtend.

  2. Schritt 2. Scrollen Sie zu Organizing. Prüfen Sie Default organize pattern und Destination behavior; angezeigt wird Ask every time. Lesen Sie darüber die Hinweise zu lokaler Verarbeitung und Berichten.

  3. Schritt 3. Prüfen Sie Vorschaugröße, Sortierung, Datums- und Größenanzeigen, automatisches Öffnen der Library nach Scans und das Merken der letzten Bibliotheksansicht.

  4. Schritt 4. Aktivieren Sie Larger text für bessere Lesbarkeit. Prüfen Sie geänderte Schrift und Navigation, bevor Sie fortfahren.

  5. Schritt 5. Deaktivieren Sie Larger text, um hier zur Standardschrift zurückzukehren. Larger buttons, Reduced motion und weitere Führungseinstellungen können dem Benutzer angepasst werden.

  6. Schritt 6. Scrollen Sie zu Maintenance. Die Speicherwerte betreffen nur erzeugte Anwendungsdateien. Refresh Usage aktualisiert sie; Clear Thumbnail Cache betrifft Vorschauen und war hier nicht erforderlich.

  7. Schritt 7. Öffnen Sie Advanced date policy. Lesen Sie jede aktivierte Datumsquelle und die Warnung für Filesystem last modified. Änderungen gelten für neue Scans, erneute Analysen und Organisationsvorschauen.

  8. Schritt 8. Wählen Sie Reset Settings to Defaults zunächst nur zur Prüfung der Bestätigung. Gelöscht würden Einstellungen, Quellen, Bibliotheksindex, Fortschritt und Vorschaubildcache. Originale und organisierte Kopien bleiben unverändert.

  9. Schritt 9. Wählen Sie Cancel, um den Testkatalog zu erhalten. Weder das reale Benutzerprofil noch das isolierte Testprofil wurde zurückgesetzt.

  • Ein Neustart löscht mehr als eine Darstellungseinstellung. Bewahren Sie benötigte Berichte und Informationen auf, bevor Sie den lokalen Katalog zurücksetzen.
  • Das bloße Öffnen von Settings schreibt vorhandene Datumswerte nicht neu. Verwenden Sie die ausdrückliche Analyse, wenn Katalogdaten geändert werden sollen.

Sie können lokale Einstellungen ändern und Wartungs- sowie Rücksetzfolgen verstehen, ohne versehentlich den Katalog zu leeren.

12. Häufige Probleme beheben

Lesen Sie vor einer Wiederholung die aktuelle Meldung. Prüfen Sie Quelle, Filter, Muster und Ziel. Die folgenden Bilder zeigen echte, gefahrlos nachgestellte Zustände mit ausschließlich entbehrlichen Beispieldaten.

  1. Schritt 1. Prüfen Sie bei No photos match your choices zuerst Search media. Ein nicht passender Dateinamenteil kann alle Ergebnisse ausblenden, obwohl Medien im Katalog stehen.

  2. Schritt 2. Ersetzen Sie die Eingabe durch einen bekannten Dateinamenteil, hier garden. Prüfen Sie zurückgekehrte Ergebnisse, bevor Sie andere Einstellungen ändern.

  3. Schritt 3. Prüfen Sie den Verfügbarkeitsfilter. Unavailable only liefert keine passenden verfügbaren Originale. Ein einschränkender Filter beweist keinen Dateiverlust.

  4. Schritt 4. Wählen Sie Show All Photos auf der Leerseite. Prüfen Sie anschließend Suchfeld und Filter.

  5. Schritt 5. Prüfen Sie bei Folder is unavailable or cannot be opened unter Current folder Schreibweise, Verbindung und Zugriff. Das Beispiel nutzt einen nicht existierenden Pfad; Select This Folder ist gesperrt.

  6. Schritt 6. Geben Sie einen vorhandenen richtigen Ordner ein und wählen Sie Go. Ein leerer Ordner zeigt null unterstützte Medien. Wählen Sie einen Medienordner oder brechen Sie ab.

  7. Schritt 7. Auch ein Ordner mit ausschließlich nicht unterstützten Dateien kann null Medien zeigen. Der Textordner gilt nicht als Foto- oder Videosammlung. Other Files werden beim Organisieren separat ausgewählt.

  8. Schritt 8. Verwenden Sie für Custom die angezeigten Token und relative Segmente. Das Beispiel mit einem übergeordneten Pfad wird als leeres oder durchlaufendes Segment abgelehnt; COPY bleibt gesperrt.

  9. Schritt 9. Korrigieren Sie das Muster, etwa zu {YYYY}\{YYYY-MM}. Öffnen und schließen Sie im geprüften Build die Pattern-Liste erneut, um den gültigen Plan zu bestätigen.

  10. Schritt 10. Lesen Sie vor Remove Folder die Bestätigung. Sie entfernt Katalogeinträge und damit die Anzeige in der Library; Originaldateien und Quellordner werden nicht gelöscht.

  11. Schritt 11. Bestätigen Sie Remove from MEDIA KOLFAT nur für die Testquelle und prüfen Sie die erhaltenen Originale. Fügen Sie den Ordner manuell erneut hinzu und scannen Sie ihn vor einer Organisation.

  • Ohne ausgewählten Dateityp bleibt Continue gesperrt. Öffnen Sie Choose File Types und wählen Sie die tatsächlich gewünschten unterstützten Typen.
  • Nach einem Pfadfehler kann die bisherige Vorschau stehen bleiben. Beachten Sie Fehlermeldung und deaktiviertes Select This Folder; die alten Vorschauen gehören nicht zum unerreichbaren Pfad.
  • Prüfen Sie bei Ziel- oder Platzproblemen den genauen Pfad, halten Sie das Ziel verbunden, wählen Sie gegebenenfalls einen anderen beschreibbaren Ordner und lassen Sie die angezeigte Reserve frei. Wiederholen Sie nichts gegen ein unerwartetes Ziel.
  • Prüfen Sie nach einer Unterbrechung Activity, TXT-Bericht und fertige Dateien vor dem erneuten Start. Warnungen oder ein Abbruch benötigen Aufmerksamkeit, auch wenn Kopien vorhanden sind.
  • Quellenentfernung wurde nur im isolierten Katalog gezeigt. Danach wurden alle 17 Quelldateien unverändert verifiziert und für das MOVE-Beispiel erneut registriert.

Sie können leere Ergebnisse von fehlenden Originalen unterscheiden, sichere Eingabefehler korrigieren und bei der Wiederherstellung Belege erhalten.
