Privacidad

1. Resumen

Kolfat procura mantener el tratamiento de datos personales claro y mínimo. MEDIA KOLFAT está pensado principalmente para organizar tus propias fotos y vídeos.

2. Tus archivos y procesamiento local

MEDIA KOLFAT puede acceder a carpetas, fotos, vídeos y metadatos que selecciones. Las funciones principales están diseñadas para procesarse localmente en tu dispositivo y tus archivos multimedia no se venden.

3. Sitio web, cookies y datos técnicos

Al visitar kolfat.app pueden procesarse datos técnicos necesarios como dirección IP, navegador, dispositivo, página solicitada y hora mediante servicios de alojamiento, DNS o seguridad.

4. Contacto, intercambio, conservación y seguridad

La información enviada por correo se usa para responder a tu solicitud. Los datos solo se procesan con proveedores cuando es necesario, no se venden y se conservan únicamente durante el tiempo necesario. Se aplican medidas de seguridad razonables.

5. Tus derechos y cambios

Según tu lugar de residencia, puedes tener derechos de acceso, rectificación, eliminación o restricción. Contacto: Contactar con KOLFAT. La política se actualizará cuando cambien de forma relevante el producto, la ley o el tratamiento.

6. Analítica web opcional

Con tu consentimiento expreso, kolfat.app utiliza Google Analytics 4 (Google Ireland Limited) para medir páginas vistas, ubicación aproximada, navegador, dispositivo y clics hacia Microsoft Store o versiones de GitHub. Sin consentimiento no se cargan scripts de Analytics ni se envían datos analíticos a Google. Pueden instalarse cookies de medición tras aceptar; la publicidad personalizada permanece desactivada. Puedes retirar el consentimiento en « Privacidad » cuando quieras. Google puede procesar datos fuera del EEE; consulta su política de privacidad. Google Privacy.
