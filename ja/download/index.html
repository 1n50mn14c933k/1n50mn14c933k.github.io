MEDIA KOLFAT

Windows向けMEDIA KOLFATをダウンロード

写真や動画の整理をWindows上でローカルに行える公式版をご利用ください。

MEDIA KOLFATMicrosoft Store

Microsoft Storeを使う理由

公式ストアはインストールと更新の方法を統一し、非公式サイトで改変されたインストーラーを入手する危険を減らします。

MEDIA KOLFATでできること

整理

ガイド付きまたは高度な操作で日付別フォルダーを作成します。

確認

ライブラリの閲覧、写真の回転、履歴やレポートの確認ができます。

重複検出

同じ内容のファイルを見つけ、削除前に確認できます。

ローカル処理

自分で管理するファイルとフォルダーを使って作業します。

大量の整理を始める前に

  1. 重要な写真や動画は別の場所にもバックアップしてください。
  2. 元と保存先のアクセス権および空き容量を確認してください。
  3. 初めての場合はガイド付きのコピー操作を選んでください。
  4. 元ファイルを削除する前に結果とレポートを確認してください。
