COPY と MOVE：安全に写真を整理する方法

まずコピーし、移動は明示的に選び、最後に結果を確認する方法。

安全第一：元のファイルは別の場所にバックアップしてください。整理はバックアップの代わりになりません。

1. 元ファイルを守る

大切な写真は別のディスクやバックアップシステムに保管してから作業します。

2. Guided COPY から始める

ガイド付きモードは元のファイルを残したまま、新しい整理済みコピーを作ります。

3. MOVE は慎重に選ぶ

Windows の Advanced Mode では MOVE を明示的に選べます。Linux ベータでは MOVE は無効、macOS は未公開です。

4. 小さなサンプルで試す

写真、動画、重複ファイル、日付不明のファイルを含めて、容量とアクセス権を確認します。

5. 削除前に検証する

整理後のファイルを開き、件数とレポートを確認します。進捗が完了しただけで元データを消さないでください。
